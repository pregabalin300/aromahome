git add .AromaHome
Интернет-магазин свечей ручной работы.

## Технологии
- Node.js + Express
- SQL Server (mssql)
- HTML, CSS, JavaScript
- Docker
- GitHub Actions

## Функционал
- Каталог свечей с фильтрами по аромату, воску и цене
- Карточка товара с описанием
- Корзина и оформление заказа
- Регистрация и вход
- Личный кабинет с историей заказов
- Избранное
