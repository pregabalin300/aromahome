# Деплой AromaHome

## Схема архитектуры
[Браузер] -> (HTTPS 443) -> [Nginx] -> (HTTP 3000) -> [Node.js App] -> [Supabase (Cloud)]

## Таблица сервисов
| Сервис | Технология | Внутренний порт | Продакшен-сервер |
| :--- | :--- | :--- | :--- |
| app | Node.js (Express) | 3000 | node (server/index.js) |
| nginx | Nginx | 80, 443 | Nginx |

## Переменные окружения и секреты
- `DATABASE_URL` — строка подключения к Supabase (секрет)
- Сертификаты в папке `certs/` (секрет)

## Команды для запуска и остановки
- Запуск: `docker compose up --build -d`
- Остановка: `docker compose down`
- Просмотр логов: `docker compose logs -f`

## Список ошибок и способы их устранения
В ходе выполнения работы критических ошибок при запуске Docker Compose не возникло. 
Были устранены следующие нюансы на этапе подготовки:
1. Конфликт портов: старые контейнеры с прошлых практических занятий занимали порт 3000. Решение: удалены через Docker Desktop.
2. Отсутствие mkcert в PATH: после установки потребовался перезапуск терминала для применения изменений.

## Что нужно изменить для реального сервера?
1. Арендовать сервер (VPS).
2. Зарегистрировать реальный домен (например, `aromahome.ru`).
3. Получить настоящий SSL-сертификат через Let's Encrypt.
4. Настроить GitHub Actions для автоматического деплоя (CD).
